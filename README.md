# Personal Introduction Program

## 📌 Project Overview
This project is a simple Python program built for Week 1 of the Intern Tasks. It prompts the user for their name, age, and favorite hobby using basic input handling, stores the answers in variables, and displays a friendly, formatted welcome message.

## 🛠️ Features & Technical Details
- **User Input:** Uses `input()` to dynamically capture user data.
- **Variables:** Stores text and numerical input for processing.
- **String Formatting:** Uses Python `f-strings` to generate personalized output.
